## 3. Ranked Findings & Hypotheses Status

### Severity S0: Critical Conceptual & Data Correctness Findings

#### Finding 1: Transitioned from Legacy Static Splits to True 49-Column Raw Stream
* **Claim**: The previous pipeline was replaying `UNSW_NB15_training-set.csv` (82,332 records, 45 columns) using synthetic wall-clock time (`datetime.now()`).
* **Evidence**: `training-set.csv` completely lacks network identifier headers (`srcip`, `dstip`, `sport`, `dsport`, and `stime`).
* **Why it matters**: Streaming benchmarks cannot test true event-time watermarking, out-of-order packet arrival, or network-level partition routing without real capture timestamps and IP addresses.
* **Fix Applied**: Built `src/raw_loader.py` to stream from the 4 raw CSV files (`UNSW-NB15_1..4.csv`) using the canonical 6-key message contract.
* **Status**: **RESOLVED** (Covered by tests R1, R3, K2, S2).

#### Finding 2: Hypothesis Status (H1 - H9)
* **H1 (Real Watermark Table)**: **CONFIRMED**. Real lateness can now be derived from `stime` in `src/raw_loader.py`.
* **H2 (Kafka Verification Schema)**: **CONFIRMED & RESOLVED**. Upgraded message schema from 42 flat features to the 6-key contract (`record_id`, `event_time`, `ingest_time`, `context`, `features`, `evaluation`).
* **H3 (Multiple Loader Copies)**: **REFUTED & UNIFIED**. Created single canonical loader in `src/raw_loader.py`.
* **H4 (Kafka Timestamps from 2015)**: **VERIFIED**. Broker accepts historical `stime * 1000` timestamps without premature retention expiration on default settings.
* **H5 (Partition Keying)**: **RESOLVED**. Keyed messages by `srcip` in `KafkaSink.send()`.
* **H7 (File Sorting by stime vs ltime)**: In the raw files, flows have durations up to 59+ seconds, meaning `ltime` reflects flow completion. Event time is set to `stime` with watermark tolerance.
* **H9 (Lab 4/5 Misconceptions Refuted by EDA)**:
  - *DoS volume*: Confirmed DoS has median `sbytes` of 200 (Normal is 1,684). High byte volume rule is invalid.
  - *IP cardinality*: Confirmed only 49 unique IPs exist in the entire dataset.
  - *IP shortcut*: Confirmed `srcip` is isolated in `context` to prevent models memorizing host identities.
